# ICheatHub — агент

Программа, которая сама заходит на твои онлайн-пары в МТС Линк и присылает звук на платформу ICheatHub:
там из него получаются конспекты.

## Как поставить

1. Скачай `icheathub-agent-full.zip` из [последнего релиза](https://github.com/nemkom1/icheathub-agent/releases/latest).
2. Правой кнопкой по архиву → «Извлечь всё».
3. В распакованной папке запусти `START-AGENT.bat` и привяжи агента на сайте.

Python ставить не нужно, он уже внутри. Если что-то не так — запусти `CHECK-PC.bat` и пришли получившийся архив.

Здесь лежат только готовые сборки агента. Сама платформа — в отдельном закрытом репозитории.
